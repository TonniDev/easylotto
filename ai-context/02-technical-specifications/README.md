# Technical Specifications

This directory contains detailed technical architecture and implementation specifications.

## Files

### technical-architecture.md
**Purpose**: System architecture, tech stack, and design patterns
**Audience**: AI agents working on technical implementation
**When to read**: Before making architectural decisions or major code changes
**Key content**:
- Technology stack (Next.js, TypeScript, PostgreSQL, etc.)
- Project structure and organization
- Design patterns and conventions

### database-schema.md
**Purpose**: Database structure, relationships, and data models
**Audience**: AI agents working with data or database operations
**When to read**: Before creating/modifying database queries or schema
**Key content**:
- Complete database schema
- Table relationships and constraints
- Data types and validation rules

### api-endpoints.md
**Purpose**: API documentation and endpoint specifications
**Audience**: AI agents working on API development or integration
**When to read**: Before creating new endpoints or modifying existing ones
**Key content**:
- Complete API endpoint documentation
- Request/response formats
- Authentication and authorization requirements

### data-synchronization.md
**Purpose**: Data sync processes, cron jobs, and automation
**Audience**: AI agents working on data processing or automation
**When to read**: Before modifying data sync processes or cron jobs
**Key content**:
- External data sources and sync processes
- Cron job schedules and implementations
- Data validation and error handling

## Usage Notes

- These documents provide the technical foundation for implementation
- Always check existing patterns before introducing new ones
- Update these documents when making architectural changes
