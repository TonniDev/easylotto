# Project Documentation

This directory contains high-level project information and overview documents.

## Files

### project-overview.md
**Purpose**: Core project description, goals, and educational mission
**Audience**: All AI agents and developers
**When to read**: First document to read when starting work on EasyLotto
**Key content**: 
- Project's educational mission (lottery risk awareness)
- Target audience and user goals
- Success metrics and business objectives

### features-and-functionality.md
**Purpose**: Current features and functionality overview
**Audience**: AI agents working on feature development
**When to read**: Before proposing new features or modifying existing ones
**Key content**:
- Complete list of implemented features
- User workflows and interactions
- Feature dependencies and relationships

## Usage Notes

- Start with `project-overview.md` to understand the "why" behind EasyLotto
- Use `features-and-functionality.md` to understand the "what" that currently exists
- These documents provide the foundation for all other technical decisions
