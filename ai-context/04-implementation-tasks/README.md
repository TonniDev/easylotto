# Implementation Tasks

This directory contains task lists and implementation guides for AI agents.

## Files

### implementation-roadmap.md
**Purpose**: Phased implementation plan with timelines and priorities
**Audience**: AI agents and project managers planning work
**When to read**: When planning implementation phases or setting priorities
**Key content**:
- Implementation phases and timelines
- Task priorities and dependencies
- Success metrics and milestones

### missing-features-tasks.md
**Purpose**: Comprehensive task breakdown with full technical specifications
**Audience**: AI agents capable of complex technical implementation
**When to read**: When looking for detailed implementation tasks
**Key content**:
- Detailed task specifications
- Technical requirements and constraints
- Testing and quality requirements
- Domain-driven design approach

### augment-agent-tasks.md
**Purpose**: Specific task format optimized for Augment Code agents
**Audience**: Augment Code AI agents
**When to read**: When working with Augment's codebase context engine
**Key content**:
- Augment-specific task formatting
- File-level implementation details
- Code organization guidelines
- Testing strategies

### general-ai-tasks.md
**Purpose**: Simplified task prompts for other AI assistants
**Audience**: General-purpose AI assistants (ChatGPT, Claude, etc.)
**When to read**: When working with non-specialized AI tools
**Key content**:
- Clear, actionable prompts
- Simplified technical requirements
- Educational focus guidelines
- Success criteria

## Usage Notes

- Choose the task format that matches your AI agent's capabilities
- All tasks prioritize educational value over technical complexity
- Follow TDD (Test-Driven Development) and DDD (Domain-Driven Design) principles
- Update task lists as work is completed or priorities change
